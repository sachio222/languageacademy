A grammar lesson teaches one pattern, or a small set that belong together, so that every word the learner already has can be used in it.

1. Present each pattern with a concept card: what it says, how it is built, and an example made only of known words.
2. Give each new verb a conjugation (the Verb forms step's data): one row per person in order of use in speech, with its English, sound group, stem and silent letters. The learner meets, says and types each form there, so the forms need no cards and never sit in a bare table. Other form sets (contractions, possessives) go in a table.
3. Teach the few new words the plan lists, each first met inside the new pattern.
4. Build the items so the learner produces the pattern: transformations from a known pattern into the new one, gap-fills on the part that changes, and responses in the situation.
5. Name the mistakes a learner of this pattern makes, and write items that catch them.
