A guide gathers into one rule what the learner has already met in several lessons. It teaches nothing new: every example comes from lessons before it.

1. State the rule in one line the learner can keep.
2. Lay out the cases in parts, each with a heading, a short explanation and examples taken from earlier lessons.
3. Where a table shows the rule best, use a table.
4. End with three checks that ask the learner to apply the rule.
5. A lesson never depends on something only a guide says.
